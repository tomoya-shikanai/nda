# 業務ソフト（RacroS III）の DB の構造（タイヤの伝票まわり）

2026-11-04 夜に、事務所の PC の SQL Server（`.\S1DATABASE2019`）を **読むだけ** で調べた結果。
列名・型・マスタ（工賃の台帳）と、件数の集計だけから推定した。客の情報（氏名・住所・電話・車台番号・ナンバー・備考）は見ていないし、ここにも書かない。
店の数字（件数・金額）は公開リポジトリに書かない。集計の結果は `data/private/racros/`（.gitignore）にある。

確度: **確** = 値の分布で裏づけた／**推** = 列名と分布からの推定／**未** = 分からない。

## データベース

| DB | 中身 | 確度 |
|---|---|---|
| `RS3_DATA` | 今年度の業務データ（511 テーブル）。伝票は 2026-01 以降だけが入っている | 確（伝票の日付の最小・最大） |
| `RS3_SYARE` | 車歴（過去の伝票の履歴）。1989〜2025 年の伝票。`RS3_DATA` と伝票番号は重ならない | 確 |
| `RS3_SISU` | 作業の指数（標準作業時間）の台帳 | 推 |
| `RS3_KATA` | 型式の台帳 | 推 |
| `RS3_JJ` | 住所コードなど | 推 |
| `RS3_WORK` | 作業用の一時テーブル | 推 |

年度の境で `RS3_DATA` の伝票が `RS3_SYARE` へ移るらしい（`RS3_DATA` が 2026-01-04 から始まり、`RS3_SYARE` が 2025-12-30 で終わる）。**集計は両方を合わせて読む。**
過去の保管データ（`C:\RACROS3\DATA\DATA01`〜`18` の `.MDF`）は SQL Server につながっておらず、今回は扱っていない。

## 伝票: 見出し `TJNL_DAT` と明細 `SYAJNL_DAT`

`TJNL_DENNO`（伝票番号）で 1 対多につながる。明細の無い見出し・見出しの無い明細は無かった（確）。両方の DB に同じ形である。

### 見出し `TJNL_DAT`（335 列。使うのは次だけ）

| 列 | 意味 | 確度 | 取り出しでの扱い |
|---|---|---|---|
| `TJNL_DENNO` | 伝票番号（DB をまたいで一意） | 確 | 仮名 `伝票00001` |
| `TJNL_YMD` | 伝票の日付（yyyyMMdd の数） | 確 | そのまま |
| `TJNL_KOKCD` | 顧客コード | 推 | 仮名 `顧客A` |
| `TJNL_CARCD` | 車両コード | 推 | 仮名 `車両001` |
| `TJNL_DENSYU`・`TJNL_TYPE`・`TJNL_URIKBN` | 伝票の種別・区分（値は 0〜5） | 未（意味は画面で確かめる） | そのまま（コード） |
| `TJNL_KDEL` | 削除の印（0 以外は削除） | 推 | そのまま。集計では 0 以外を除く |
| `TJNL_MAKER` | メーカーのコード | 推 | そのまま（コード） |
| `TJNL_SYASYU` | 車種名（半角カナ。例: ワゴンR） | 確 | 3 台以上にある値だけ残し、ほかは `<少数>` |
| `TJNL_KATA` | 型式 | 推 | 同上 |
| `TJNL_KM` | 走行距離 | 推 | 1 万 km の幅に丸める |
| `TJNL_TIRE1_F`・`_R` | 夏タイヤのサイズ（前・後）。速度記号が S・H・V 等 | 確（値の分布） | サイズだけを読む（例: `155/65R14`） |
| `TJNL_TIRE2_F`・`_R` | 冬タイヤのサイズ（前・後）。速度記号が Q | 確（値の分布） | 同上 |
| `TJNL_KOU_URI`・`TJNL_BUH_URI` ほか `*_URI`・`*_GEN`・`*_NEBI` | 工賃・部品などの区分ごとの売上・原価・値引き | 推 | 今回は使わない |

サイズの欄が入っているのは 2013 年ごろ以降の伝票の一部だけ。

**出さない列**（客の情報か、判断のつかない自由記述）: `NM1`・`NM2`・`RYAKU`・`KANA`（氏名・略称・カナ）、`POST`・`JYU1`・`JYU2`（住所）、`TEL`、`RIKUJI`・`BANGO`・`NO`（ナンバー）、`SYATAI`（車台番号）、`GAIATE*`（宛名）、`TEKI`（摘要）、`CS_TXT1`〜`5`、`CHUBAN`、`BATTERY`、`JCM_*`・`EXT_*`・`MORE_*` ほか、上の表に無い列すべて。

### 明細 `SYAJNL_DAT`（49 列）

| 列 | 意味 | 確度 | 取り出しでの扱い |
|---|---|---|---|
| `SYAJNL_DENNO`・`SYAJNL_DENSEQ` | 伝票番号・行の番号 | 確 | 伝票は仮名、行の番号はそのまま |
| `SYAJNL_CARCD` | 車両コード（見出しと同じ） | 推 | 使わない（見出しの方を仮名にする） |
| `SYAJNL_KOUCD` | 工賃コード（`KOUM_DAT` の `KOUM_CODE`。0 は手入力の行） | 確 | そのまま |
| `SYAJNL_BUHCD` | 部品コード（ほぼ 0） | 推 | そのまま |
| `SYAJNL_BYKBN`・`SYAJNL_SAGKBN` | 行の区分・作業の区分 | 未 | そのまま（コード） |
| `SYAJNL_NM` | 品名・作業名。**手で書き換えられる自由記述** | 確 | 下の「品名の扱い」 |
| `SYAJNL_HINBAN` | 品番 | 確 | 英数字だけ残す。0 で始まる 10 桁以上の数字は電話番号と見分けられないので捨てる |
| `SYAJNL_S_SISU` | 作業の指数 | 推 | そのまま |
| `SYAJNL_S_KIN` | 工賃の金額（その行の合計） | 確（例: 履き替え 4 本で 1 行） | そのまま |
| `SYAJNL_B_SU` | 数量の **10 倍**（40 = 4 本） | 確（履き替えの行が 40、トラックが 60） | そのまま。集計で ÷10 |
| `SYAJNL_B_TAN`・`SYAJNL_B_KIN` | 部品の単価・金額 | 推 | そのまま |
| `SYAJNL_YMD`・`SYAJNL_KM` | 日付・走行距離（見出しと同じ） | 推 | 使わない |
| `SYAJNL_*_U*ZEI`・`EXT_*ZEI` | 税の内訳 | 未 | 使わない。金額が税抜か税込かは未確認 |
| `SYAJNL_BUHINF` | 部品の情報（中身不明の文字列） | 未 | **出さない** |

### 品名の扱い（`SYAJNL_NM`）

品名は工賃マスタから入るが、画面で書き換えられる。客の名前や事情が書かれ得るので、次の順で決める（`office/racros/RacrosMask.psm1` の `Protect-FreeText`）。

1. 電話番号・長い数字・メール・敬称（様・さん・殿など）・住所の語・車台番号やナンバーの形を含む → `<除外>`
2. 3 人以上の客の伝票に現れる文言（表記を NFKC でそろえて数える）→ そのまま残す
3. タイヤと読める（サイズか銘柄がある）→ `<タイヤ 銘柄 サイズ>`（読めた部分だけ）
4. それ以外 → `<自由記述>`

行の分類（履き替え・組み替え・バランスなど）は、伏せる前に PC の中で決めて列 `category` に入れる。

### タイヤ関係の工賃コード（`KOUM_DAT`）

| 分類 | コード | 名前（マスタの表記） |
|---|---|---|
| 履き替え `tire_swap` | 277, 50105, 50123, 50128, 50129 | タイヤ・履き替え、タイヤ脱着、シーズン履き替え、夏・冬履替（ホイール付／なし） |
| 組み替え `tire_mount` | 278, 50121, 50122 | タイヤ・組み替え、組替（バランス込／組替のみ） |
| バランス `balance` | 279, 309, 50110 | ホイール・バランス、バランス測定（アルミ） |
| バルブ `valve` | 296 | タイヤ・ゴムバルブ |
| タイヤ本体 `tire` | 50100, 50101, 50102, 50103, 82570, 88220, 520001 | タイヤ、ラジアル、スタッドレス、チューブ、フロント／リヤ・タイヤ |
| パンク修理・ローテーション | 50124, 50120 | — |

ただし 50100（タイヤ）は「タイヤ・履き替え」と書き換えて作業に使われていることが多い。分類は品名の語を先に見る（`Get-TireLineCategory`）。
廃タイヤ・保管料・エアバルブは工賃コード 0（手入力）で入っていることが多く、品名で拾う。

## タイヤの伝票の定義

明細のどれかが、上の工賃コードを持つか、品名に「タイヤ」「スタッドレス」（半角も）を含む伝票。種類は:

- `mount`: 組み替えの行があるか、タイヤ本体を売った（部品の金額が 0 より大きい）
- `swap`: それ以外で、履き替えの行がある
- `other`: パンク修理・保管・廃タイヤだけ、など

タイヤの伝票には車検・点検の行もよく一緒に載る（その他の行）。

## 分かっていないこと（画面で鹿内さん・父に確かめる）

1. `TJNL_DENSYU`・`TJNL_TYPE`・`TJNL_URIKBN` の値の意味（見積・納品・請求の別か。今は区別せずに数えている）。
2. 明細の金額は税抜か税込か。
3. `SYAJNL_BYKBN`・`SYAJNL_SAGKBN` の意味。
4. 年度の境で `RS3_DATA` から `RS3_SYARE` へ移る時期と、その間の伝票が二重に数えられないか（今は伝票番号が重ならないことだけ確かめた）。
5. タイヤ本体の行の多くは品名が「タイヤ」だけで、サイズが書かれていない（見出しのサイズの欄も空のことが多い）。サイズ別の値段は、件数が少ない。
