# 請求書を作るときに参考にする情報

Claude が父の声から請求の明細を作るとき、何を見てよいか・どう使うかの一覧。
仕組み（候補 → 抽出 → 照合 → 聞き返し）は `docs/design/invoice-verify.md`、業務ソフトの DB の構造は `docs/racros-schema.md` にある。

このリポジトリは公開なので、店の件数・割合・単価はここに書かない。数字は事務所の PC の `data/private/racros/`（Git に入らない）にある。

## 原則

- **明細の数（数量・単価・金額）の出所は、父の発話と料金表だけ。** 過去の伝票の傾向で数を埋めない（「推測で埋めない」）。
- 過去の伝票の傾向は、**父が承認するときの参考**として並べるだけにする。
- 分からないことは確認事項にする。ただし、傾向を理由に質問を増やさない（CLAUDE.md「発火率を上げるための質問を作らない」）。

| 2 | 料金表（正式名・別名・単価・単位） | `data/ledger.json`（`lib/ledger/lookup.ts`） | 品目の同定、単価と単位の照合（#3） | 当たらない・あいまいな品目を推測で決める（`found:false` にする） |

### 3 の台帳の引き方

- 車種とサイズで引く。`invoice_ledger` を `model+size`（車種×サイズ）→ `size` → `all` の順に探し、見つかった一番細かい区分を使う。
- 種類は `swap`（履き替え）と `mount`（組み替え。タイヤ本体の交換を含む）。
- 返るもの: 作業の分類ごとの「その伝票に載る割合」「代表の品名」「数量」「1 行の金額と 1 本あたりの中央値と幅」。
- 金額は直近 3 年の分だけで出す（値上げがあったため）。年ごとの推移は `work_prices.*.amount_by_year`。
- 台帳の値は 3 台以上の車がある区分だけ。少ない区分は出ない。

### 未決: 台帳の値をどこまで使うか

次は案で、決めていない（`docs/decisions.md` で決める）。

- 承認画面で、明細の金額が台帳の幅から外れていたら目印を付ける（確認事項にはしない）。
- 台帳でよく一緒に載る行（例: 組み替えとバランス）が明細に無いとき、承認画面に「よく一緒に載る行」として並べる（質問にはしない）。

## 業務ソフトの書き方の慣習

過去の伝票（業務ソフトの DB）から分かったこと。数字は書かない。確度は `docs/racros-schema.md` と同じ（確 = 値で裏づけた／推 = 推定／未 = 分からない）。

### 品目の名前

- 正式名は工賃マスタの表記で、**半角カナ**（「ﾀｲﾔ･履き替え」「ﾀｲﾔ･組み替え」「ﾎｲｰﾙ･ﾊﾞﾗﾝｽ」「ﾎｲｰﾙﾊﾞﾗﾝｽ測定(ｱﾙﾐﾎｲｰﾙ)」「ﾀｲﾔ･ｺﾞﾑﾊﾞﾙﾌﾞ･TR413 CLX」）。料金表と照らすときは NFKC でそろえる。（確）
- 品名は伝票ごとに書き換えられ、実際によく書き換えられている。マスタの名前のまま入っているとは限らない。（確）
- 廃タイヤ・ホイールナットはマスタに無く、工賃コード 0 の手入力の行で入れる。保管料も専用の品目が無く、手入力か、履き替え（277）の品名を「タイヤ・履き替え・保管袋タイプ」（NFKC でそろえた形）のように書き換えて入れる。（確）
- タイヤ本体は、品名に銘柄とサイズを手で書く（「タイヤ」だけの行も多い）。（確）
- バルブ: 父は「バルブ」と言うが、伝票ではマスタの名前（ゴムバルブ）で入る。業務ソフトの中で「バルブ」は電球や弁の名前にも使われるので、タイヤの作業がある明細のときだけタイヤのバルブに当てる（#41 のコメント）。（確）

### 数量と金額の入れ方

- 1 本ずつの単価 × 本数の行と、**4 本分をまとめて数量 0・金額だけの 1 行**の、2 つの書き方が混ざっている。数量 0 は「数量なし」の意味で、0 本ではない。（確）
- 廃タイヤは「廃タイヤ・15インチ」のように品名にインチを書き、**インチで単価が変わる**。料金表はインチ別に持つ。（確）
- 単価は伝票ごとに手で打つのが普通の使い方。タイヤ関係はマスタの売値がほぼ 0 で、毎回入れている。（確）
- DB の数量は 10 倍の値で入る（4 本 → 40）。画面で入れるのは本数そのもの（推）。
- 値段は年によって上がっている。古い伝票の金額を今の値段として使わない。（確）

### 伝票の組み合わせ

- 多いのは「履き替え 4 本だけ」。組み替えのときは、組み替え・バランス・バルブ・廃タイヤ（とタイヤ本体）が一緒に載ることが多い。（確）
- 「バルブ＋廃タイヤだけ」でタイヤ本体と組み替えの行が無い伝票がある。意味は分からない（未）。
- タイヤの伝票には、車検・点検など別の作業の行もよく一緒に載る。（確）
- 履き替えは 11 月と 4 月に集中する。組み替えは一年中ある。（確）

## 分かっていないこと（鹿内さん・父に確かめる）

1. 請求書に単位が出るか。出るなら、バルブは「本」か「個」か（DB に単位の記録が無い）。#3・#41
2. 明細の金額は税抜か税込か。
3. 伝票の種別（見積・納品・請求）の区別。
4. 「バルブ＋廃タイヤだけ」の伝票の意味。
5. 父が電球のことも「バルブ」と呼ぶか。
