## 相棒のキャラクター

整備服（紺のつなぎ）とキャップを身につけた、藤色のタコ。袖から 2 本、裾から 4 本の腕が出ている。胸に「んだびょん」の名札、キャップに「ん」の記章、胸ポケットに黄色のペン。

### Clawd と区別するための工夫

| Clawd の特徴 | 相棒 |
|---|---|
| ピクセル絵（四角の組み合わせ） | 曲線だけで描く。四角いドットを使わない |
| オレンジ（テラコッタ）の体 | 体は藤色（`#8f78d8`）。テラコッタはキャップの記章の小さな丸だけ |
| 横長の体に脚が並ぶカニのような形 | 縦に長い。大きな丸い頭＋つなぎ＋腕 6 本（見えている分）。頭が体の半分を占める |
| 目は小さな四角 | 目は白目と黒目のある丸。まぶた・眉・口で表情を変える |
| 服を着ていない | 整備服とキャップ。名札と記章で「店の相棒」と分かる |

オマージュは 1 点だけにした。キャップの「ん」の記章の丸を、Claude の色に近いテラコッタ（`#d97757`）にしている。差し色の小さな面積にとどめ、形や体の色では寄せない。要らなければ黄色にする。

### 状態ごとの見た目と文言

| 状態 | 上の札（色） | 表情 | 動き（CSS アニメーション） | 吹き出し（聞き取った言葉 → 今していること） | 確認事項・明細 |
|---|---|---|---|---|---|
| 待機中 `idle` | 待機中（薄い灰青） | まぶたを半分下ろした落ち着いた目、小さな笑顔 | ゆっくり息をする（3.6 秒）、ときどきまばたき。レンチを下げて持つ | 「んだ、Claude」と声をかけてください → **待っています。手は整備のままで。** | ありません／まだありません |
| 聞いている `listening` | 聞いている（青） | 目を大きく開き、黒目は吹き出しの方へ。口は小さな「お」 | 右の腕を耳に当て、頭を傾ける。音の波が 2 本広がる | 「タイヤ4本、組替とバランスだ。廃タイヤも▍（聞き取り途中、カーソルが点滅） → **聞いています** | ありません／まだありません |
| 考え中 `thinking` | 考え中（紫） | 黒目が上を向く。口は波線 | 首を左右にかしげる。頭の上の点が順に灯る | 「タイヤ4本、組替とバランスだ。廃タイヤも4本、処分してけって。バルブも替えた。」 → **明細に分けています** | ありません／分けています… |
| 請求書を作っている `drafting` | 請求書を作っている（深緑） | 黒目が手元を見る。口を結ぶ | 両腕でバインダーを持ち、ペンを動かす。紙の線が伸びる。体が少し早く揺れる | 同上 → **請求書を作っています** | ありません／2 行入れた・1 行作っている・1 行まだ |
| 確かめたいことがある `asking` | 確かめたいことがある（黄色・黒字） | 眉を上げ、目を大きく、口を開ける | 前に乗り出す。頭の横の「？」が跳ねる。片腕を差し出す | 同上 → **バルブは何本ですか**（黄色の帯で強調）。答えが読めなければ **もう一度お願いします。バルブは何本ですか** | バルブは何本ですか（黄色の太枠、今の質問と「ほか N 問」の 1 行）／エアバルブ交換の行が「確認待ち」で数量を出さない |
| 承認待ち（`asking` で確認事項 0 件） | 承認待ち（深緑） | 小さな笑顔、黒目は吹き出しの方へ | 請求書を抱え、右の腕を耳に当てて待つ。音の波（緑） | 同上 → **合っていれば「請求書頼む」と言ってください**。確認事項が残っているのに言えば **まだ確かめたいことがあります。…** | ありません／全行入れた・合計 |
| 終わった `done` | 終わった（緑） | 目を細めた笑顔、口を開けて笑う | 両腕を上げ、レンチを掲げて跳ねる。星がまたたく | 「4本」 → **4 行入れました。発行は人が押してください** | ✓ エアバルブ交換 4本（答えてもらった）／4 行すべて入れた |

文言の決まり:
- 分からない値は「値段？」と出し、推測の金額を出さない。確認事項に答えてもらった値は「答えてもらった」と出所を付ける。
- 終わったときは「発行は人が押してください」で締める。相棒は発行しない。
- 1920×1080 で明細の合計の行が必ず見えるようにする。吹き出しの高さに上限（聞き取った言葉は最新の 2 行、台詞は長さで文字を小さくし 3 行まで）、確認事項の帯は 1 行、明細は 4 行を超えたら詰め、収まらなければ最初の確認待ちの行が見える所までスクロールし、合計の行は欄の下に固定する。
- 状態は色だけで伝えない。上の札の文言、明細の各行の記号（✓・…・?・・）と言葉（入れた・作っている・確認待ち・まだ）でも分ける。

## 配色

明るい工場（蛍光灯・外光）で、画面の映り込みがあっても読めるよう、明るい背景に濃い文字を基本にした。暗い背景は映り込みで読みにくくなる。

| 用途 | 色 | コントラスト比（WCAG） |
|---|---|---|
| 背景 | 生成り `#f4f1e8`（真っ白より眩しくない） | 文字 `#1d1b26` と 15.0:1 |
| 吹き出し・枠の中 | 白 `#ffffff`、縁は `#1d1b26` | 文字と 17.0:1 |
| 待機中の札 | `#dfe5ee` に `#33415c` | 8.1:1 |
| 聞いている | `#1f6fd1` に白 | 4.9:1 |
| 考え中 | `#6b4fc9` に白 | 5.9:1 |
| 作っている | `#0f7f65` に白 | 4.9:1 |
| 確かめたい | `#ffc400` に `#1d1b26` | 10.6:1 |
| 終わった | `#23772d` に白 | 5.6:1 |
| 補助の文字 | `#5d5a6b` を白に | 6.7:1 |

札の文字は 58px の太字なので、大きな文字の基準（3:1）は全部の状態で大きく超える。確かめたいことがあるときだけ黄色にし、いちばん目に入るようにした。

## 文字の大きさの決め方

前提（実機で確かめる）: モニターは 24〜32 型の 1920×1080、整備士は 2〜4m 離れている。

- 24 型の 1 画素は約 0.28mm、32 型は約 0.37mm。
- 案内表示でよく使う目安「離れた距離の 1/120 の文字の高さで楽に読める」「1/250 が読める下限」を使う。3m なら楽に読めるのが 25mm、下限が 12mm。
- 27 型（約 0.31mm）で換算すると、楽に読めるのが約 80px、下限が約 40px。

| 文字 | 大きさ（1920×1080 のとき） | 役割 |
|---|---|---|
| 今していること（吹き出しの下段） | 76px 太字 | 3m から楽に読める |
| 聞き取った言葉 | 52px | 2〜3m で読める。近づいて確かめる言葉 |
| 状態の札 | 58px 太字 | 色と合わせて遠くから分かる |
| 確認事項・明細 | 40〜42px | 下限。近づけば読める |
| 小見出し（聞き取った言葉 等） | 34px | 補助 |
| 「試作・架空のデータ」、切り替えの帯 | 22〜24px | 遠くから読む必要が無いもの |

画面の大きさは CSS の `--u`（1920×1080 を基準にした 1px）で縮尺するので、ブラウザの窓が小さくても比率は崩れない。

## 模擬の請求書画面

- 上部の黒い帯に「**模擬画面**（実際は市販の整備ソフトに入力）」を常に出す。動画のどの瞬間を切り取っても映る位置。
- 見た目は一般的な業務ソフトの入力画面（灰色の窓・入力欄・明細の表・小計・消費税・合計・一時保存・確定）。RacroS III の配色・配置・項目の並びは写していない（RacroS III の画面は見ずに作った）。
- 「▶ 再生」で、架空の明細が 1.4 秒ごとに 1 行ずつ入る。入った行は一瞬黄色に光る。
- 最後は「確定」の手前で止まる。確定ボタンが黄色の枠で点滅し、隣に「最後の確定は人が押します →」と出る。押すと「確定しました（模擬）」と出る（人が押す場面の撮影用）。
- 明細は確認事項に答えてもらった後の値（エアバルブ 4 個。単価は架空の料金表の値）で入れる。

## 声のキャラクターの候補（VOICEVOX）

音声の実装はまだしない。VOICEVOX は商用・非商用とも使えるが、VOICEVOX を使ったと分かるクレジットが要り、生成した音声の扱いは声ごとの規約に従う（`docs/research.md`「声とキャラクター」）。工場は騒がしいので、低すぎない・はっきりした声がよい。

| 案 | 声 | 合う点 | 気になる点 | クレジット | 規約の確認 |
|---|---|---|---|---|---|
| A | 東北イタコ | 東北ずん子プロジェクトの東北 3 姉妹の 1 人で、名前の由来が青森（恐山）のイタコ。青森の店の相棒として話の筋が通る。落ち着いた大人の声 | 声のキャラクター自身に見た目がある（相棒の絵とは別人）。VOICEVOX 0.26.0 に入っているかは実機で確かめる | 画面の隅と README に「VOICEVOX:東北イタコ」 | 未確認。東北ずん子プロジェクトの規約（ずんだもんと同じ窓口の見込み）を個別に確かめる |
| B | ずんだもん | 規約を確認済み（商用可、表記は「VOICEVOX:ずんだもん」）。高めの声で騒音の中でも通りやすい。知名度が高い | 声の印象が強く、整備の相棒より「ずんだもん」に見える。語尾「〜なのだ」を使わなければ印象は和らぐ | 「VOICEVOX:ずんだもん」 | 確認済（`docs/research.md`）。クレジット無しは 1 キャラクター 40 万円＋税 |
| C | 玄野武宏（男性） | 父と同じ「店の人」として聞こえる、落ち着いた男性の声。父の年代に違和感が少ない | 低めの声は工場の騒音（エアインパクトなど）に埋もれやすい。実機で聞き比べる | 「VOICEVOX:玄野武宏」 | 未確認。声ごとの規約を確かめる |

**決定（2026-11-04）**: B ずんだもんで進める。相棒の名前は「んだびょん」（名札に表示。キャップの記章は「ん」のまま）。クレジット「VOICEVOX:ずんだもん」を画面の隅と README に入れる。将来、娘の声をサンプリングして入れたい（保護者である鹿内さんの同意のもと。今は実装しない）。A・C は採らない。どの案でも、定型の質問（「値段が料金表にありません」など）は前もって WAV にしておけば、Pi 5 の速さに左右されない。

## 鹿内さんに決めてほしいこと

- 相棒の姿はこの方向（藤色のタコ・紺のつなぎ・キャップ）でよいか。体の色を変えるなら何色か（青森のりんごの赤は、Clawd のオレンジに近づくので避けたい）。
- キャップの記章のテラコッタ（Claude へのオマージュ）を残すか、黄色にするか。
- 状態の文言（上の表の太字）。特に「待っています。手は整備のままで。」と「発行は人が押してください」の言い回し。父が普段使う言葉に寄せるか（津軽弁を混ぜるか）。
- 状態は 6 つでよいか。README には「入力している」（整備ソフトに入れている）があるが、試作では「請求書を作っている」に含めた。分けるか。
- 模擬画面の注釈の言い回し。`docs/decisions.md` では「実際は市販の整備ソフト（RacroS III）に入力する」と製品名を入れているが、画面では製品名を入れていない。動画で製品名を出すか。
- モニターの実物の大きさと、整備士が立つ位置からの距離（文字の大きさの前提を確かめる）。
