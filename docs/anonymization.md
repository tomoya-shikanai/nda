# 匿名化ルール

- コミット禁止: 実名、電話番号、住所、車台番号（VIN）、ナンバープレート、客の顔。
- 仮名: `顧客A` `車両001` `事業者X` `業者P`。番号は案件ごとに振る。
- 実名との対応表はリポジトリ外（`~/private/nda-mapping/`）。
- 録音: 原本は `data/recordings/`（.gitignore）。公開する音は同意済みで、個人が特定される発話を切った別コピーだけ。
- 客の声: 同意メモ（日付・氏名はリポ外・用途）が無い録音は保存しない。
- 客と車の一覧（名前・読み・ナンバー下 4 桁・車種）はリポジトリ外に置き、`NDA_CUSTOMERS_PATH` で渡す。試験は架空の `tests/fixtures/customers.json` だけ。照合に使う名前と 4 桁は伏せ字にしてから保存・抽出する（#45）。
