# 匿名化ルール

- コミット禁止: 実名、電話番号、住所、車台番号（VIN）、ナンバープレート、客の顔。
- 仮名: `顧客A` `車両001` `事業者X` `業者P`。番号は案件ごとに振る。
- 実名との対応表はリポジトリ外（`~/private/nda-mapping/`）。業務ソフト（RacroS III）の内部番号と仮名の対応表は、事務所の PC の `C:\Users\PRS\nda-private\racros\`。
- 業務ソフトの DB から取り出すときは、許可リストの列だけを出し、自由記述は 3 人以上の客に共通する文言だけを残す。仮名は `顧客A`・`車両001`・`伝票00001`（`office/racros/`、`docs/racros-schema.md`）。
- 録音: 原本は `data/recordings/`（.gitignore）。公開する音は同意済みで、個人が特定される発話を切った別コピーだけ。
- 客の声: 同意メモ（日付・氏名はリポ外・用途）が無い録音は保存しない。
- 客と車の一覧は事務所の PC にだけある（工場にも Claude にも出さない、#25）。工場は名前らしい部分と 4 桁を一覧なしで伏せ字にしてから保存・抽出し、4 桁を含む文の原文だけを照合の問い合わせ（メモリの上だけ）で事務所に送る。事務所が返す姓と車種（label）は画面に出すだけで保存しない。試験と偽の事務所は架空の `tests/fixtures/customers.json` だけ。
- 既知の限界（#25）: 工場の伏せ字は一覧なしで、敬称の前の名前と、ナンバーかもしれない数（円の付かない 4 桁以上）を含む文と、その前後の文のうち料金表の品目の語（品目名・別名・言い換え）を含まないものを丸ごと伏せる。ナンバーから 2 文以上離れた敬称の無い姓（「田中。脱着4本。以上。1234。」の「田中」）と、ナンバーを言わない発話の敬称の無い姓は伏せられず、抽出と作業ファイルに残る。
- 既知の限界（客を先に言う話し方）: ナンバーの隣の文でも品目の語を含めば残すので、その文の敬称の無い姓（「田中、脱着4本。1111。」の「田中」）は Claude と作業ファイルに渡る。
