# 事務所の記録（RacroS III の操作）

事務所の Windows PC で、整備ソフト RacroS III をどう操作したかを記録するプログラムです。

## 何をするか

- RacroS III が起動している間だけ記録します。起動していないときは何も残しません。
- 他のアプリ（ブラウザ・メールなど）の操作は記録しません。前面の窓・クリックした部品が RacroS III のものかを毎回確かめ、違えば捨てます。クリックは、押した瞬間にその場所にあった窓が RacroS III のものかで決めます。
- 読むだけです。RacroS III に入力したり、クリックしたりはしません。
- キー入力の文字そのものは残しません。Tab・Enter・Esc・F1〜F12・矢印などの特別なキーと、Ctrl・Alt との組み合わせ（`ctrl+S` など、英数字だけ）を `key` の行に残し、その前に打った普通の文字の数（`chars_before`）を付けます。RacroS III が前面のときだけ数えます。
- 欄の値は、欄から離れたときに「欄の値が変わったこと」を残します。値そのものは、どの欄でも `***` に伏せ、文字数（`value_len`、値の変化では `before_len`・`after_len`）だけを残します。
- RacroS III の文字の欄（`TextEdit`）と数の欄（`NumEdit`）は、入力した値が部品の名前（Name）に出ます。これらは Name を値として扱い、ほかの欄と同じく文字数だけを残します。対象のクラスは `config.json` の `name_value_classes` で変えられます。
- ツールバー（`msvb_lib_toolbar`）のボタンには名前が無いので、押した位置からボタンの名前を決めて `toolbar_button` に残します（伝票 `M_NOU.exe` と顧客・車両 `M_CAR.exe`。分からなければ `?`）。伝票の画面は、新しく入れるときと作った伝票を開いたときとでボタンの並びが変わるので、並びごとの表を持ち、候補が割れたら `転用|新規` のように並べます。帯の左端からの位置（`toolbar_dx`）も残します。位置は 1920×1080・拡大 100% で測ったものです。
- 窓の題名は、客を選ぶと先頭に客の名前が入ります（`[ 名前 ] - [ 画面の名前 ] - RacroSⅢ`）。「 - 」で区切って 3 つ以上あれば、後ろの 2 つだけを残し、前は `***` にします。窓・題名の帯の部品の名前と、`dump` の出力も同じように伏せます。`list` は窓の題名を出しません。
- 部品の名前は、ボタン・メニュー・タブ・チェックの欄など、画面の決まった文字の部品だけ残します。ほかの部品（一覧の行・ダイアログの文面・欄など）の名前は、客の名前が入り得るので `***` と文字数（`name_len`）にします。`dump` も同じです。
- 確認のダイアログでは、ボタンの名前（はい(Y) など）だけを `buttons` に残します。文面は残しません。
- 欄の移動・クリック・キーの行に、画面の実行ファイル名（`exe`）を付けます。
- 部品の読み取りに失敗したら、失敗した段階（`window`・`focus`・`click`）だけを捨てて、`error` の行に `stage` つきで残します。失敗の文面は部品の名前や値が入り得るので残さず、例外の型と COM のエラー番号（`0x80131505` など）だけを残します。
- パスワード欄・保護された欄の値は `***` に伏せます。パスワード欄かどうかが読めない部品は、値も文字数も残しません。同じ欄にいる間に一度でもパスワード欄と判定されたら、その欄を離れるまで前後の値とも伏せます。
- 記録を始めるとき（`session_start`）に、対象にしたプロセスの名前・pid・実行ファイルのパスを残します。違うソフトを記録していないかを後で確かめられます。
- 残すのは、窓の切り替わり（題名）、クリックした部品の名前、欄の値の変化、スクリーンショット（窓が変わったとき・ボタンなどを押したとき・文字や数の欄に初めて入ったとき。2 秒に 1 枚まで、RacroS III の窓の範囲だけ）です。
- スクリーンショットは、撮る直前と撮った直後に前面の窓が RacroS III のその窓であることを確かめ、違えば撮りません（残しません）。
  - **注意**: 常に手前に出る他の窓（通知・付箋・別のソフトの「常に手前」の小窓など）が RacroS III の窓に重なっていると、その部分は写り込みます。記録中は RacroS III の上に他の窓を重ねないでください。右下の「● 記録中」の表示（このプログラム自身の小窓）も、RacroS III の窓に重なっていれば写ります（写るのはこの表示だけです）。
  - 撮る前と後でしか確かめないので、撮っている一瞬（数十ミリ秒）だけ他の窓が前に出て、また RacroS III に戻ったときは写り得ます。

## 入れ方（最初の 1 回）

1. python.org から Python 3.12 の Windows 版（64bit、「Windows installer (64-bit)」）を入れます。最初の画面で「Add python.exe to PATH」に必ずチェックを入れます。
2. このリポジトリの `office` フォルダをコマンドプロンプトで開き、次を実行します。

   ```
   pip install -r requirements.txt
   ```

## 使い方（office フォルダで）

### 1. 対象の実行ファイル名を確かめる

RacroS III を起動しておいて、次を実行します。

```
python -m recorder list
```

窓を持つプロセスの一覧が出ます。RacroS III の行の、左端の実行ファイル名を確かめます。

対象にするのは、実行ファイル名が `target_exe` のどれかと**完全に一致する**プロセスだけです（大文字小文字は区別しません）。窓の題名や名前の一部では選びません。題名で選ぶと、「RacroS」を題名に含むブラウザのタブやフォルダの窓まで記録してしまうためです。

RacroS III は画面ごとに実行ファイルが分かれています（メニューは `RS_MENU.exe`、車検証は `M_CAR.exe` など。`C:\RACROS3\EXE` に約 350 本）。記録は、`target_exe` のどれかの名前のプロセスが 1 つでも動いている間を 1 回の記録とし、前面の窓・クリックがそのどれかのプロセスのものなら残します（窓の記録に `exe` が付きます）。この店の PC では `C:\RACROS3\EXE` の実行ファイル名をすべて `target_exe` に入れています。

既定の `RacroS.exe` は**仮の値**です。必ず `python -m recorder list` で確かめて、`recorder\config.json` を作って直します（このファイルは PC ごとの設定なので Git には入りません）。

```json
{
  "target_exe": ["RacroS3.exe"]
}
```

- `target_exe`: 実行ファイル名（`list` の左端に出た名前を `.exe` まで含めてそのまま書く。完全一致）。
- そのほかに書けるもの: `keep_days`（残す日数、既定 7）、`poll_sec`（画面を見る間隔の秒、既定 0.3）、`min_shot_interval`（スクリーンショットの最短の間隔の秒、既定 2）、`jpeg_quality`（既定 70）、`uia_timeout_ms`（画面を読む 1 回の呼び出しを待つ上限のミリ秒、既定 3000。Windows の既定は 20 秒で、RacroS III が忙しいと記録が約 60 秒止まっていた。0 で Windows の既定）、`show_indicator`（右下の表示、既定 true）、`root`（記録の置き場）。

### 2. 画面の部品を書き出す

RacroS III で記録したい画面（例: 請求書の入力）を前に出して、次を実行します。

```
python -m recorder dump
```

部品ツリー（`dump-日時.txt`）と窓のスクリーンショット（`dump-日時-番号.jpg`）が `%LOCALAPPDATA%\nda-recorder\dumps` に出ます。スクリーンショットは前面にある RacroS III の窓だけを撮ります。コマンドプロンプトが前面にあると撮らないので、RacroS III の画面をクリックして前に出し、`timeout /t 5 & python -m recorder dump` のように少し待ってから書き出します（テキストに「前面に無いので撮っていない」と出たら撮れていません）。読むだけで、RacroS III は操作しません。部品に値（`value=***(n 文字)`）が出ているかを見ます。

### 3. 常駐させる

```
python -m recorder run
```

止めるときはコマンドプロンプトで Ctrl+C を押します。窓を出さずに動かすときは `start-recorder.bat` をダブルクリックします（止めるときはタスクマネージャーで `pythonw.exe` を終了します）。

## 記録の置き場

- `%LOCALAPPDATA%\nda-recorder\<日付>\session-<時刻>\` に、RacroS III を起動するたびにフォルダを分けて書きます。
  - `events.jsonl` … 1 行 1 件の記録（窓・クリック・欄の値の変化など）。
  - `screenshots\` … スクリーンショット（JPEG）。
- 7 日より古い日付のフォルダと、`dumps` の中の 7 日より古いファイルは自動で消えます（起動時と、動いている間 1 時間ごと）。今書いているセッションのフォルダは消しません。
- 動かしたまま日付が変わると、新しい日付のフォルダに切り替えて書き続けます（新しいフォルダの 1 行目は `session_continue` で、`from` に前のフォルダが入ります）。
- 記録中（RacroS III が起動している間）は、画面の右下に赤い「● 記録中（RacroS）」が出ます。RacroS III を閉じると消えます。

## ログオン時に自動で起動する

タスクスケジューラに登録します。コマンドプロンプトを「管理者として実行」で開き、次を実行します（`C:\nda\office` は実際の office フォルダの場所に置き換えます）。

```
schtasks /Create /TN "nda-recorder" /SC ONLOGON /TR "\"C:\nda\office\start-recorder.bat\""
```

`start-recorder.bat` は office フォルダに移ってから `pythonw -m recorder run` を起動します。

- RacroS III を管理者として動かしている場合は、末尾に `/RL HIGHEST` を足します（次の節）。
- ノート PC の場合は、タスクスケジューラの画面でこのタスクを開き、「条件」の「コンピューターを AC 電源で使用している場合のみタスクを開始する」と、「設定」の「タスクを停止するまでの時間」のチェックを外します。
- 消すとき: `schtasks /Delete /TN "nda-recorder" /F`

## RacroS III が管理者権限で動いている場合

Windows には、普通の権限のプログラムが管理者権限のプログラムの画面を読めないようにする仕組み（UIPI）があります。RacroS III が管理者権限で動いていると、普通の権限の記録では窓も部品も読めず、何も残りません。そのときは、記録も管理者権限で動かします。

- 確かめ方: タスクマネージャーの「詳細」で列の見出しを右クリック →「列の選択」→「管理者特権」にチェック。RacroS III の行が「はい」なら管理者権限です。
- 手で動かすとき: コマンドプロンプトを「管理者として実行」で開いてから `python -m recorder run`。
- 自動起動: 上の `schtasks` に `/RL HIGHEST` を足して登録します。

## 明日の最初の確認手順

1. RacroS III を起動し、`python -m recorder list` で RacroS III の行を探します。
2. 実行ファイル名が仮の値の `RacroS.exe` と違えば、`recorder\config.json` の `target_exe` をその名前に直し、`python -m recorder dump` で対象が見つかるかを確かめます。
3. コマンドプロンプトで `timeout /t 5 & python -m recorder dump` を打ち、5 秒以内に RacroS III の請求書の入力などの画面をクリックして前に出します（前面が RacroS III でないと JPEG は撮りません）。`dumps` のテキストに部品の名前・値が出ているか、JPEG が RacroS III の窓になっているかを見ます。何も出ないときは、RacroS III が管理者権限で動いていないかを確かめます。
4. `python -m recorder run` を動かし、右下に赤い表示が出るのを確かめます。RacroS III で 1 件だけ操作します（画面を開く・欄に入れる・ボタンを押す）。終わったら Ctrl+C で止めます。
5. `%LOCALAPPDATA%\nda-recorder\<今日の日付>\session-…\events.jsonl` をメモ帳で開き、1 行目の `session_start` の `exe`・`path` が RacroS III のものかを見ます。続いて、操作した順に `window`・`click`・`focus`・`value_changed` が並んでいるかを見ます。`error` の行があれば、その中身を控えます。`screenshots` の JPEG が RacroS III の窓だけを写しているか（他のアプリが写り込んでいないか）を見ます。
6. 記録を動かしたまま普段どおり数分操作し、PC が重くならないか、RacroS III の動きが遅くならないかを見ます。タスクマネージャーで `python.exe` の CPU とメモリも見ます。
7. RacroS III は VB6 で作られている可能性が高いです。dump でウィンドウのクラス名（`ThunderRT6…` なら VB6）と、明細の表の中身が読めるかを見ます。値が `(legacy)` と付いて出ていれば、LegacyIAccessiblePattern（MSAA）から読めています。記録では `value_source: "legacy"` になります。
8. 同じ伝票を重ねて開くと排他警告（8001）が出るので、記録中も重ねて開かないでください。

`start-recorder.bat`（`pythonw`）で動かすと、うまく動かないときにエラーが画面に出ません。その場合はコマンドプロンプトで `python -m recorder run` を動かすと、エラーが表示されます。
